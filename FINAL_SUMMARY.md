## 🔄 How It Works (Simple Version)

```
1. User enters credentials
         ↓
2. Click login/signup button
         ↓
3. App sends data to your Django server
         ↓
4. Server verifies and sends back tokens
         ↓
5. App saves tokens automatically
         ↓
6. App redirects to main screens
         ↓
7. User is logged in! 🎉
```
